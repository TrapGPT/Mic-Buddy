# MicBuddy

MicBuddy project scaffold. Add your Bolt.new export or continue building here.

## Git on Windows PowerShell

If `git` is not recognized, either restart the terminal after installing Git, or run Git via:

`& "C:\Program Files\Git\cmd\git.exe"`

Or add `C:\Program Files\Git\cmd` to your user **PATH** (Windows Settings → Environment Variables).

## Push to GitHub

1. Create the repo **TrapGPT/mic-buddy** on GitHub (empty repo, default branch can be `main`).
2. Sign in when prompted (HTTPS uses Git Credential Manager), or use SSH and `git remote set-url origin git@github.com:TrapGPT/mic-buddy.git`.
3. From this folder: `git push -u origin main`.
